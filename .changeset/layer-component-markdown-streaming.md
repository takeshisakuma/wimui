`MarkdownRenderer` と `StreamingText` のスタイルを、他と同じ `@layer component` の中へ入れた（T243 の第 7 弾）。

どちらもカスケードレイヤーの外にあったため、**利用者が書いた CSS がこれらの内部スタイルに勝てなかった**。

**描画は変わらない**（AI・タイポグラフィ系の 157 ストーリーを撮り比べ、アニメーションを持つ 3 ストーリーの揺れを対照で除いたうえで差分ゼロ）。

> **上書きしている場合は確認を。** これらを自前の CSS で上書きしていた場合、**これまで効かなかった上書きが効くようになる**。とくに `MarkdownRenderer` は見出し・リスト・コードブロックなど素の要素に当てているので、同じ要素を狙った指定がある場合は見え方が変わりうる。
