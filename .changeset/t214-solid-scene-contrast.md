solid のボタンで、**面の上に乗るシーンまで含めると 4.5:1 を割っていた** 2 つの色を一段深いトーンに差し替えた。

solid のボタンは地色の上に `--wim-glass-gradient`（白 0.08 → 透明）が重なる。**素の地では通るのに、白が乗る上側で落ちる**という形で、宣言も導出も正しいまま欠陥になっていた。

- `--wim-color-success` … `#28853f` → **`#306f42`**（PCCS の Strong → Deep）。素 4.65 → 6.04、シーン込み 4.04 → **5.06**。緑は Vivid トーンだと白文字に対して構造的に明るすぎる（3.29）ため、他の intent と違って Vivid を使えない。Deep にすることで danger のシーン込み 5.08 とほぼ同じ位置に着く。
- `soft` プリセットの accent … `#6a64ae` → **`#5c5791`**（Bright → Soft）。素 5.19 → 6.51、シーン込み 4.40 → **5.38**。くすんだ紫という preset の性格は保っている。

`--wim-color-success` は 24 コンポーネント（Alert / Badge / Toast / Progress / Timeline など）から参照されているので、**成功を表す緑がわずかに濃くなる**。`soft` プリセットを使っている場合はアクセントの紫も同様。

`danger` / `primary` / `warning` / `info` と、`bold` / `minimal` プリセットは変更していない。

あわせて `check:contrast-scene` を追加した。従来の `check:contrast` は塗りとサーフェスまでしか見ておらず、**その上に乗るものを勘定に入れる場所がどこにも無かった**（旧 success のコメントが「4.65:1（AA）」と素の値だけを根拠にしていたのがその証拠）。
