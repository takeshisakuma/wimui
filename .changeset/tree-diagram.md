TreeDiagram を追加しました。組織図・サイトマップ・分類のような木を、座標を渡さずデータだけから並べます（`wimui` / `wimui/data-display`）。

- 親は子の中央に置かれ、兄弟の部分木は重なりません。向きは上から下（`vertical`・既定）と左から右（`horizontal`）を選べます。
- 部分木は折りたためます。折りたたんだノードの開閉ボタンには、隠れている人数が「+3」のように出ます。開閉は制御（`expandedValues`）と非制御（`defaultExpandedValues`。既定は全部開く）の両方に対応します。
- 既定では読み取り専用です。`onSelect` を渡すと、クリック・Enter・Space でノードを選べます。
- キーボード操作は `TreeView` と同じ WAI-ARIA の tree です（上下・左右・Home / End）。各カードは階層・兄弟の中の位置・開閉の状態を持つ `treeitem` です。
- カードの大きさは固定で（`nodeWidth` / `nodeHeight`）、何かを測る前に配置が決まります。図が置き場より広ければ、ページを押し広げずに自分の箱の中でスクロールします。
- 扱うのは木だけです。親が 2 人いる形（家系図）は対象外です。
