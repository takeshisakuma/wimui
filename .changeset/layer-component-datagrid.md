`DataGrid` のスタイルを、他と同じ `@layer component` の中へ入れた（T243 の第 3 弾）。

`DataGrid` はカスケードレイヤーの外にあったため、**利用者が書いた CSS が `DataGrid` の内部スタイルに勝てなかった**。0.29.2 で直したカード表示の固定列のずれ（行が 10px ずれてカードからはみ出す）も、元をたどればこれが原因だった。

**描画は変わらない**（`DataGrid` / `Table` / `List` と、それらを使う画面の 93 ストーリーを撮り比べて差分ゼロ）。

> **上書きしている場合は確認を。** `DataGrid` を自前の CSS で上書きしていた場合、**これまで効かなかった上書きが効くようになる**。
