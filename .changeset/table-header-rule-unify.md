`Table` / `DataGrid` の見出し行まわりを 3 点直した。

**見出しと本文の区切り線の太さを 2px に揃えた。** これまでは指定した prop によって **1px / 2px / 3px / 4px の 4 通り**に描かれていた（画素で実測）。`bordered` を付けると見出しの 2px がセルの罫線 1px に上書きされ、`stickyHeader` は別に影で線を描くので border と足し算になっていた。これからは見出しの下線を 1 つの機構（内側の影）だけが描く。**スクロール中に線が細る問題も併せて解消**する（border はスクロールすると 2px が 1px になっていた）。

**カード表示（`mobileCard`）で、固定列（`fixed`）の行だけがずれてカードからはみ出していたのを直した。** 実測で 10px 右へ入り込み、右端はカードの枠を 9px 超えていた。列見出しのラベルも表示されるようになった。通常幅での固定列の挙動は変わらない。

**見出し行の背景指定を削除した。** 指定はあったが行の背景に隠れて**一度も描画されていなかった**。仮に有効にしても `striped` の奇数行と同じ色なので、見出しと 1 行目が区別できなくなる。区切りは上記の下線が担う。

> **視覚スナップショット（VRT など）を持っている場合、`Table` / `DataGrid` を含む画面はほぼすべて差分が出る。** 見出しの下線の太さが変わるため。API は変わらない。
