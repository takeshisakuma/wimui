`NodeGraph` の自前スタイルを、他と同じ `@layer component` の中へ入れた（T243 の第 5 弾）。

`InteractiveGraph` と同じく、**React Flow（`reactflow`）の見た目を上書きしている部分だけはレイヤーの外に残している**。`reactflow` が配る CSS はどのレイヤーにも属さないため、レイヤーの中から上書きすると詳細度に関わらず負ける。

**描画は変わらない**（light / dark の両方で、`NodeGraph` と可視化カテゴリの 52 ストーリーを撮り比べて差分ゼロ）。

> **上書きしている場合は確認を。** `NodeGraph` 自身の枠・背景・角丸やツールバーを自前の CSS で上書きしていた場合、**これまで効かなかった上書きが効くようになる**。React Flow 側の見た目（ノード・辺・コントロール・ミニマップ・背景）の優先順は変わらない。
