`Kanban` の列・`ContextMenu` のグループ・`CommandPalette` のグループが、**支援技術から名前のある区切りとして辿れるようになった**。

いずれも見出しのように見えるテキストが素の `div` で、グループ自体にロールや名前が無かったため、読み上げでは中身が一続きに読まれていた（どのカードがどの列のものか、どの候補がどの分類のものかが分からない状態）。

- `Kanban` の列 … `role="group"` と列タイトルによる名前を付けた
- `ContextMenu` のグループ … `role="group"` はあったが名前が無かったので `aria-labelledby` を足した
- `CommandPalette` のグループ … `role="group"` ごと無かったので足した（`listbox > group > option` の形になる）

**見出し（`h2`〜`h6`）にはしていない。** メニューやカンバンの列は文書の節ではないので、ARIA のパターンとしては「グループに名前を付ける」のが正しく、同じ形が `Menu` の `MenuItemGroup` に既にあった。そちらに揃えている。

見た目は変わらない。公開 API の変更も無い。
