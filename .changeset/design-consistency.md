同じ役割なのに見え方が割れていた部品を揃えました。**どれも既定の見た目が変わります。**

- **Accordion**: 閉じた見出しの地を面の色（`surface`）にしました。以前は休止時からホバーと同じ色で、ホバーしても変化がありませんでした。ホバーと開いた見出しは従来どおり淡い色です。
- **Tabs**: 選択中のタブを太字にするのをやめました。選択のたびにタブの幅が数 px 動いていました。選択は文字色と下線で示し、面は塗りません（以前は「選択中」と「未選択をホバー」が同じ面でした）。
- **TreeView**: 選択行を、List の選択行と同じ淡い面にしました。以前は primary のベタ塗り＋白文字でした。
- **Snackbar / Notification**: 角丸と影を Toast と同じ（`radius-overlay` / `shadow-overlay`）にしました。Snackbar は角丸 4px → 8px、影が一段軽くなります。浮かせた Notification も同じです。
- **Drawer**: 見出しのサイズと余白を Dialog に合わせました（見出し `xl` → `lg`、余白 10px → 16px）。
- **Pagination / TreeView の無効**: 文字色だけで示すようにしました。以前は文字色に加えて透明度も掛かり、ほかの部品の無効より一段薄く見えていました。
- **押したときの縮み**: 小さいボタン用のトークン `--wim-scale-active-sm`（0.9）を足し、Toast / Snackbar / Alert の閉じるボタンで使います（Alert は 0.95 → 0.9）。Pagination は既定の `--wim-scale-active`（0.98）にしました。
