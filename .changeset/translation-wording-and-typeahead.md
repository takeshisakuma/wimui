訳語を見直し、PhoneInput の頭文字の検索を、表示言語によらず使えるようにしました。

- **QueryBuilder（日本語）**: 演算子のラベルを「次」で始まる形に揃えました（「等しい」→「次と等しい」、「含む」→「次を含む」、「で始まる」→「次で始まる」、「より大きい」→「次より大きい」、「より後」→「次より後」など）。「以上 / 以下 / 以降 / 以前 / 空である / 空でない」は変わりません。
- **QueryBuilder（ポルトガル語）**: 「É nulo / Não é nulo」を「Está vazio / Não está vazio」にしました。
- **PhoneInput**: 文字を打って国へ移動する操作が、表示している国名に当たらないとき、英語の国名、国コード（`jp` など）の順に照合します。日本語の表示では国名を直接打てなかった（IME の変換中のキー入力は届かない）ので、`j` で日本、`kr` で韓国へ移動できるようになります。表示名で当たるものが先です（英語の表示で `g` は Germany）。
