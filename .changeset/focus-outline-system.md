## 既定値の変更（利用者の画面が黙って変わる）

キーボードのフォーカス表示を、どのテーマでも見えるように作り直しました。

- **既定のフォーカス表示を outline（2px の実線・外側に 2px 空ける）にしました。** 以前は白 2px と primary 50% を重ねた `box-shadow` の輪でした。
  - light では白い面に白の内輪が溶け、外側の primary 50% が面に対して 2.39:1 しかありませんでした（フォーカス表示に求める 3:1 に届かない）。
  - Windows のハイコントラスト表示（`forced-colors`）では `box-shadow` が消されるため、何も表示されていませんでした。
  - 部品が自分の `box-shadow`（影）を持っていると、フォーカスの輪がその影に負けて消えていました。
- **dark のフォーカス色を明るくしました。** `--wim-color-focus-outline` は light と同じ primary（#055d87）で、dark の面（#393939）に対して 1.61:1 しかありませんでした。dark では `--wim-color-text-accent`（#97cbe0）を使います（面に対して 6.56:1 / 一段明るい面に対して 4.66:1 / アプリの地に対して 8.60:1）。
- **`--wim-shadow-focus` と `--wim-shadow-focus-ring` をフォーカス色の 2px の実線にしました。** 以前はそれぞれ「白 2px ＋ primary 50%」「primary 15% の 3px のにじみ」でした。これらのトークンで自前のフォーカス表示を作っている場合も、両テーマで見えるようになります。
- **`TreeView`** のルートでフォーカスの表示が消えないようにしました。

自前で `outline: none` を書いてフォーカス表示を消している場合、新しい既定の outline も消えます。その場合は `--wim-color-focus-outline` を使った表示を用意してください。
