`CodeBlock` provides a robust container for displaying code snippets with syntax highlighting, optional line numbering, and a built-in "Copy to Clipboard" utility. It supports a collapsible mode to keep long snippets from overwhelming the page layout.

<Canvas of={CodeBlockStories.Default} />

## <T k="common:doc.design_intent_title" />

In AI interfaces, code snippets are frequent and often lengthy. `CodeBlock` standardizes their presentation, ensuring consistent typography (monospaced) and providing essential utilities like copy-pasting. The collapsible feature allows users to scan the surrounding conversation without being forced to scroll through long blocks of code.

## <T k="common:doc.content_guidelines_title" />

<ul>
  <li>Always specify the `language` prop to ensure correct syntax highlighting and accessibility hints.</li>
  <li>Use `showLineNumbers` for multi-line snippets where line-specific discussion might occur.</li>
  <li>Keep `maxLines` at a reasonable height (e.g., 10-15 lines) when `isCollapsible` is true.</li>
</ul>

## <T k="common:doc.motion_spec_title" />

Expand/collapse transitions use CSS Grid animations with the `--wim-duration-normal` token. The chevron icon rotates 180 degrees to indicate state change.

## <T k="common:doc.a11y_spec_title" />

<ul>
  <li>The copy button has a descriptive `aria-label` which updates when the content is successfully copied.</li>
  <li>The code content is wrapped in a `<pre>` and `<code>` tag for semantic correctness.</li>
  <li>Line numbers are `user-select: none` to prevent them from being included in manual text selections.</li>
  <li>All buttons are focusable and support keyboard activation.</li>
</ul>

## <T k="common:doc.best_practices_title" />

<ul>
  <li>Disable the copy button if the code is empty or if the feature is not applicable to the context.</li>
  <li>Use the `onCopy` callback to trigger analytics or custom toast notifications.</li>
  <li>Ensure the background color of the `CodeBlock` contrasts well with the surrounding application background.</li>
</ul>

## <T k="common:doc.responsive_title" />

The `CodeBlock` container fills the width of its parent and provides horizontal scrolling for long lines. On narrow viewports, it's recommended to use the collapsible mode to save vertical space.
