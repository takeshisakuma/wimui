`AIResponseFeedback` provides thumbs-up/down feedback controls and an optional regenerate button for rating AI-generated responses. It supports both controlled and uncontrolled usage, toggling feedback off when the same button is clicked twice.

<Canvas of={AIResponseFeedbackStories.InContext} />

## <T k="common:doc.design_intent_title" />

Inline feedback signals let users rate individual AI responses without disrupting the reading flow. The compact icon-button layout keeps the UI uncluttered while staying accessible via keyboard and screen readers.

## <T k="common:doc.content_guidelines_title" />

<ul>
  <li>Do not add text labels next to the icon buttons — rely on `aria-label` for accessibility.</li>
  <li>Show a brief confirmation message (e.g. "Thanks for your feedback!") in the parent, not inside this component.</li>
</ul>

## <T k="common:doc.motion_spec_title" />

Button state transitions (hover/active/selected) use the `--wim-duration-fast` token for immediate tactile feedback.

## <T k="common:doc.a11y_spec_title" />

<ul>
  <li>Each button carries a descriptive `aria-label` sourced from i18n keys.</li>
  <li>`aria-pressed` reflects the current selection state for screen readers.</li>
  <li>The divider between feedback and regenerate is `aria-hidden`.</li>
  <li>All interactive elements are keyboard-reachable and show `:focus-visible` outlines.</li>
</ul>

## <T k="common:doc.best_practices_title" />

<ul>
  <li>Keep the component disabled while a response is still streaming to prevent premature feedback.</li>
  <li>Persist the feedback value to your backend on selection, not on unmount.</li>
  <li>Use the controlled `feedback` prop when the parent needs to reset state (e.g. on regenerate).</li>
</ul>
