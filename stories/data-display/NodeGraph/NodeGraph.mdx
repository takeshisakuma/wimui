インタラクティブなノードベースのダイアグラムを描画するコンポーネントです。React Flow をラップしており、承認フローやAIエージェントのパイプライン可視化など、複雑なグラフ構造の表示と編集に使用します。

<Controls of={NodeGraphStories.Default} />

## <T k="doc.design_intent_title" />

ノード（処理単位）とエッジ（接続）で構成される有向グラフをユーザーが視覚的に把握・編集できるよう設計されています。ドラッグによるノード移動や接続の作成をサポートし、読み取り専用モードも提供します。

## <T k="doc.content_guidelines_title" />

<ul>
  <li>ノードラベルは短く、一目で内容が伝わるようにしてください（例：「承認」「送信」「条件分岐」）。</li>
  <li>エッジのラベルには状態遷移の条件（例：「success」「error」）を記述します。</li>
</ul>

## <T k="doc.motion_spec_title" />

ノードのドラッグ操作はネイティブのブラウザ挙動を使用します。React Flow が提供するデフォルトのアニメーションを維持してください。

## <T k="doc.a11y_spec_title" />

<ul>
  <li>グラフ全体を `role="region"` と `aria-label` でラップしています。</li>
  <li>キーボードによるノード選択・移動は React Flow の組み込みサポートに依存します。</li>
  <li>スクリーンリーダー向けには、重要な状態変化を別途 `aria-live` 領域でアナウンスすることを推奨します。</li>
</ul>

## <T k="doc.real_world_scenarios_title" />

<ul>
  <li>**承認フローエディタ**: 申請・承認・却下のノードをドラッグ接続してワークフローを構築する。</li>
  <li>**AIパイプライン可視化**: プロンプト → LLM → 後処理の処理フローを可視化する。</li>
  <li>**データフロー図**: ETL パイプラインや API 連携の依存関係を図示する。</li>
</ul>

## <T k="doc.best_practices_title" />

<ul>
  <li>初期ノード・エッジは `nodes` / `edges` prop に渡してください。内部状態は React Flow が管理します。</li>
  <li>読み取り専用にする場合は `nodesDraggable={false}` `nodesConnectable={false}` `deleteKeyCode={null}` を組み合わせてください。</li>
  <li>コンテナに必ず明示的な高さを指定してください（例：`height: 500px`）。高さが 0 だとグラフが描画されません。</li>
</ul>

## <T k="doc.responsive_title" />

コンテナの幅・高さに応じて自動リサイズされます。モバイルでは Controls ボタンのタッチターゲットが小さくなるため、`showControls={false}` にしてジェスチャーのみで操作させることを検討してください。
