## 組み合わせパターン

`PromptInput` と `StreamingText` を組み合わせることで、シンプルな AI チャット UI を構築できます。

<table>
  <thead>
    <tr>
      <th>ユースケース</th>
      <th>構成</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>AI チャット</td>
      <td>`PromptInput`（入力） + `ThoughtProcess`（推論） + `StreamingText`（応答表示）</td>
    </tr>
    <tr>
      <td>AI 検索</td>
      <td>`SmartSearchInput`（入力） + `StreamingText`（結果要約）</td>
    </tr>
    <tr>
      <td>コードアシスタント</td>
      <td>`PromptInput`（添付あり） + `StreamingText`（コードブロック強調）</td>
    </tr>
    <tr>
      <td>ドキュメント生成</td>
      <td>`PromptInput` + `StreamingText` + 保存ボタン</td>
    </tr>
  </tbody>
</table>

## ベストプラクティス

<ul>
  <li>AI が応答を生成中は `PromptInput` の `loading={true}` を設定し、重複送信を防いでください。</li>
  <li>`StreamingText` はストリーミング完了後に `isStreaming={false}` へ切り替えてください。カーソルが消え、`aria-live` が解除されます。</li>
  <li>エラー発生時は `StreamingText` の `content` にエラーメッセージを表示するか、別途 `Alert` コンポーネントを使用してください。</li>
</ul>
